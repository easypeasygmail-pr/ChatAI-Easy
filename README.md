# ChatGPT Polska — Personal Edition

Polskojęzyczne, responsywne centrum dostępu do ChatGPT w formie Progressive Web App.

## Uruchomienie lokalne
`npm install` następnie `npm run dev`.

## Ważne
- Przycisk „Otwórz ChatGPT” otwiera oficjalny serwis https://chatgpt.com/ w nowej karcie.
- Aplikacja nie osadza ChatGPT w iframe i nie przechwytuje danych logowania.
- Panel jest niezależnym interfejsem nawigacyjnym; nie zastępuje funkcji ani subskrypcji konta OpenAI.
- PWA wymaga HTTPS do instalacji; Vercel zapewnia HTTPS.
